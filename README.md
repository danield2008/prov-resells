# PROV RESELLS

Catálogo web inicial para GitHub Pages.

## Publicación
1. Entra en Settings > Pages.
2. En Build and deployment, selecciona Deploy from a branch.
3. Selecciona main y /(root), pulsa Save.
4. La dirección será https://danield2008.github.io/prov-resells/ cuando Pages termine de desplegar.

## Aviso importante
Esta es una maqueta inicial. El panel de administración usa una contraseña incluida en el código y los productos se guardan únicamente en el navegador (localStorage). No usar con datos sensibles ni como administración segura hasta conectar Firebase Authentication, Firestore y reglas de seguridad. Las imágenes de productos y la sincronización entre dispositivos aún no están implementadas.
